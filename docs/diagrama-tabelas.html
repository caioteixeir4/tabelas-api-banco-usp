    Como atualizar este diagrama

    Tudo o que aparece vem do bloco <script id="modelo" type="application/json"> no fim deste arquivo: tabelas, campos, tipos, ligações e as tabelas de apoio. Para mudar o desenho, edite o JSON e recarregue a página (o README do repositório explica o formato).

    • Tabela nova: acrescente um objeto em tabelas e o id dela em alguma coluna de colunas.
    • Relação nova: acrescente em relacoes (pai, filho, fk, pk) e marque "fk" no campo do filho.
    • Depois de uma migração: confira com SELECT ... FROM user_tab_columns no schema e atualize estado.

    Fontes deste desenho: src/main/resources/db/migration/V1 a V4 (Flyway), conferidas no Oracle ao vivo; e oracle-init/12_exemplo_dominio_kawashi_core.sql (referência, nunca aplicada). As 4 tabelas de controle de segurança ficam no repositório regras-banco-usp e não entram aqui.

    Gerado para o TCC (USP/Esalq). Os nomes de schema usam <AMB> no lugar do ambiente (TESTE_DEV, DEV, INFRA, HOMOLOG, PROD...).
